# 🌸 Shakti: The Power Within

Shakti: The Power Within is a creative event showcase website created for the Women's Day celebration at Government Polytechnic Muzaffarpur.

The website presents the different moments of the celebration through photographs, inspirational messages, speeches, poetry performances, and interactive visual elements.

---

## ✨ Features

- 🌸 Women's Day celebration showcase
- 🏫 College event presentation
- 📸 Event photography
- 🪔 Lamp Lighting Ceremony showcase
- 🎤 Inspiring speeches section
- 📝 Poetry showcase
- 🎂 Cake Cutting Ceremony showcase
- 🎁 Gift Distribution Ceremony showcase
- 🖼️ Interactive image reveals on hover
- 🎥 Embedded poetry performance videos
- 💬 Inspirational quotes and messages
- 📱 Responsive layout for smaller screens
- ❤️ Custom event-themed design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Media Queries
- HTML Video
- Responsive Web Design

## 🎭 Event Highlights

The website captures several moments from the celebration:

- 🪔 Lamp Lighting Ceremony performed by the women professors of the institution
- 🎤 Inspiring speeches delivered by students
- 📝 Poetry performances by students
- 🎂 Cake Cutting Ceremony with the female faculty members
- 🎁 Gift Distribution Ceremony honoring the women educators

---

## 💫 Interactive Elements

The main page includes interactive image reveals where hovering over selected event activities displays related photographs.

The poetry section also includes video performances, allowing visitors to experience the creative presentations from the celebration.

---

## 📱 Responsive Design

The website includes responsive CSS rules for different screen sizes.

Images, videos, and interactive elements are adjusted for smaller screens to maintain usability and readability across devices.

---

## 🎯 Purpose

The main purpose of this project is to digitally showcase and preserve the moments of the Women's Day celebration at Government Polytechnic Muzaffarpur.

Rather than presenting the event as a simple collection of photographs, the website combines event highlights, creative performances, quotes, and interactive elements into a single visual experience.
